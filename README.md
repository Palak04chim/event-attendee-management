# EventFlow — Event & Attendee Management System

Mini Web App Project using HTML, CSS, JavaScript, Node.js, Express.js and SQLite.

## Features
- Create and search events
- Register attendees with ticket types
- Duplicate registration validation
- Event capacity validation
- Delete events and registrations
- Dashboard statistics
- REST API + Fetch API
- Persistent SQLite database

## Run
1. Install Node.js LTS.
2. Open terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

The `events.db` file is created automatically after the first run.
